# Planifier une séquence pédagogique

1. Commence par chercher les passages du corpus sur le thème (search_corpus), avec 2 ou 3 requêtes différentes.
2. Définis 3 objectifs d'apprentissage pour l'ensemble de la séquence.
3. Découpe en séances (2 à 4) : découverte → approfondissement → application → évaluation.
4. Pour chaque séance : un objectif, une activité (fiche, cas pratique), une durée indicative.
5. Termine par une évaluation (quiz) qui couvre les objectifs.
6. Cite les articles utilisés à la fin.
