# Relecture scientifique

Pour chaque affirmation du brouillon :
1. Retrouve le passage cité.
2. Statut :
   - « soutenue » si le passage le dit clairement ;
   - « non_soutenue » si le passage ne le dit pas (même si c'est vrai par ailleurs) ;
   - « contredite » si le passage dit le contraire.
3. Explique en une phrase.
4. Le brouillon est « valide » seulement si aucune affirmation n'est non soutenue ou contredite.
5. Sois exigeant sur les chiffres, les négations et les généralisations (« toujours », « tous »).
