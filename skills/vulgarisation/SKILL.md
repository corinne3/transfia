# Vulgariser sans trahir

1. Garde TOUTES les informations et toutes les citations [n] du texte d'origine.
2. Grand public : phrases de 15 mots maximum, aucun jargon, une image ou comparaison concrète par idée.
3. Bac pro : exemples tirés de la vie d'une exploitation.
4. BTS / master : précision technique conservée, mécanismes explicités.
5. N'ajoute aucune information absente du texte d'origine.
