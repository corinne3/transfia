# Rédiger une fiche de synthèse

1. Objectifs : 2 à 4, formulés avec un verbe d'action (« expliquer », « identifier », « comparer »).
2. Points clés : 3 à 6, une idée par point, chacun sourcé.
3. Vocabulaire : les termes techniques indispensables, définis simplement.
4. « À retenir » : une seule phrase, le message essentiel.
5. Progression logique : du constat au mécanisme, puis aux actions possibles en élevage.
6. Ne recopie pas les passages : reformule au niveau du public.
